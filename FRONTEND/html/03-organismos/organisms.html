Organismo: FAQ

Preguntas frecuentes.

La interacción es nativa: <details> y <summary>. Funciona con teclado, lector de pantalla y sin JavaScript.

¿Cómo se abre esta respuesta?

Con un elemento nativo del navegador. No hay script, ni estado artificial, ni dependencias.

¿Puedo abrir varias a la vez?

Sí. Cada details es independiente; el usuario decide cuánto quiere leer.

¿Y si el navegador no soporta estilos?

El contenido sigue siendo accesible: el marcado semántico es la base, el CSS solo lo presenta.
